# Performance Benchmarks

`mom6_forge` tracks performance regressions using [pytest-benchmark](https://pytest-benchmark.readthedocs.io). Benchmarks follow the `test_bench_*` naming convention and live in the existing test files — any test that accepts the `benchmark` fixture is discovered as a benchmark. The regular test workflow passes `--benchmark-disable` so benchmark bodies still run (catching functional regressions) without timing overhead; use `--benchmark-only` to run them with timing, or `--benchmark-skip` to skip entirely. CI fires `.github/workflows/benchmark.yml` on every PR, compares results against `tests/benchmark_baseline.json`, and fails if any benchmark mean exceeds 110% of baseline — regenerate it with `pytest tests/ --benchmark-only --benchmark-json=tests/benchmark_baseline.json` or download the CI artifact (preferred because CI is different than your local computer). For production-scale benchmarks on real data, see [SeaSloth](https://crocodile-cesm.github.io/SeaSloth/).
